# ChatGPT 怎么用上 GPT-6.2？只在 Work 和 Codex 里，哪些套餐有、找不到模型先查这 4 处

更新于 2026-11-18 · AI Boxy

GPT-6.2 不在平时聊天的那个菜单里。先切到 Work 或 Codex，再看自己的套餐和客户端版本。

## 要点

- GPT-6.2 Astra 和 Sol 只加进了 ChatGPT Work 和 Codex，平时聊天用的 Chat 菜单不会出现它们。
- Plus、Pro、Business、Enterprise、Edu 可以用，Enterprise 和 Edu 要等管理员打开；官方名单里没有 Free 和 Go。
- 找不到模型，先确认自己在 Work 或 Codex，再更新桌面 App 和 Codex CLI，最后看套餐和推送进度。
