# ChatGPT 桌面版打开 Codex 要验证手机号？只能用短信或 WhatsApp，邮箱和验证器替代不了

更新于 2026-11-17 · AI Boxy

这不是普通的登录验证。桌面版 Codex 这一步只接受支持的手机号，通行密钥能帮你登录账号，但替不了这一次手机验证。

## 要点

- 日常用 ChatGPT 一般不用验证手机号；在桌面版打开 Codex，或第一次创建 API 密钥时，可能会被要求验证。
- 验证码只走短信，部分国家可以用 WhatsApp，不能改成邮箱、电话或验证器 App。
- 请用自己能控制的、受支持的手机号。座机、网络电话和 Google Voice 都不行；通行密钥只能帮你登录账号，替不了这一步。
