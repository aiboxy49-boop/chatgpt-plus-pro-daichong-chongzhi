# GPT-5.5 10 月 14 日从 ChatGPT、Work 和 Codex 退役：迁移检查清单

更新于 2026-10-11 · AI Boxy

- API 中的 GPT-5.5 不受此次 ChatGPT、Work 和 Codex 退役影响。
