# ChatGPT 两步验证手机丢了、换手机收不到验证码？按这个顺序找回登录

更新于 2026-11-20 · AI Boxy

依据 OpenAI 帮助中心《Managing multi-factor authentication (MFA)》（信息核对于 2026-11-20）。MFA 开启后在 ChatGPT 和 API Platform 等 OpenAI 服务中都生效。可用方式包括验证器 App（如 Google Authenticator、Authy）、推送通知、短信或 WhatsApp 的 6 位验证码、通行密钥；可用选项因设备、国家/地区、账号类型和注册方式而异。在 ChatGPT 设置 → Security and login → Multi-factor authentication (MFA) 中开启或管理。开启多个方式时默认先用最安全的一种，登录时仍可选择任一已开启的方式。邮箱不是常规 MFA 方式；丢失某种方式时先选其他已配置的方式；全部无法使用时联系 OpenAI Support，需完成核验，可能需要几天；核验通过后支持人员会提供一次性邮箱恢复登录，这只是临时恢复，不是长期的邮箱验证方式；登录后必须添加可用的备用 MFA 方式，或在 Settings > Security and login 关闭 MFA；该恢复机会只有一次，用过后再丢失 MFA 方式时不再提供。加入 Advanced Account Security 且丢失通行密钥或安全密钥的，用恢复密钥找回。开启 MFA 不会自动退出其他设备；可在 Security and login 选择 Log out of all devices，全部退出最多可能需要 30 分钟。

## 要点

- 先在登录页换用账号里其他已开启的验证方式，比如通行密钥、推送或短信。
- 所有方式都用不了，就联系 OpenAI Support 做核验，可能要几天；通过后会给一次性邮箱恢复登录。
- 恢复机会只有一次。登录后立刻补一个备用验证方式，平时最好同时开两种。
