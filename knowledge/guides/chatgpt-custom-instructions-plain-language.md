# ChatGPT 说得太抽象、不好懂？用自定义指令先让它把话说清楚

更新于 2026-11-19 · AI Boxy

不用每条对话都重复说“说人话”。把偏好写进自定义指令，所有对话都会按这个来。

## 要点

- 网页或桌面到 Settings → Personalization，打开 Enable customization，在 Custom Instructions 里写上希望它怎么回答；手机则在 Settings 的 Customize ChatGPT 里设置。
- 可以先用一句简单、需要时再展开的偏好作为起点；免费和 Go 最多 1,500 字，Plus 和 Pro 等套餐最多 5,000 字。
- 性格设置只影响说话方式，会和自定义指令、记忆一起生效；改指令对之后的回答生效，旧对话记录不会被改写。
