# 12 月起 ChatGPT 和 Codex 共用一份额度：Plus / Pro 用户现在该做什么

更新于 2026-11-17 · AI Boxy

已确认的是共用额度、token 计量和 Instant 豁免；具体开始日期及每档额度，仍要等账户页面与官方更新。

## 要点

- 12月起Plus、Pro、Business的ChatGPT与Codex将共用用量，并按token计量；更高级模型和复杂任务通常消耗更多。
- Instant聊天不计入这份用量；合并剩余用量与重置时间将显示在Settings → Usage。
- 官方说明尚未列出具体切换日和每档token数，不据此推算额度会减少；达到限制后按账户选项等重置、升级或用积分继续合资格功能。
