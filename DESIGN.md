# Design System

## Theme

Trust-first technical guide with the established AI Boxy forest and lime identity. The page uses a light reading surface because visitors compare detailed payment and security information during normal desktop and mobile browsing.

## Color

- Ink and primary action: `#17251d`
- Reading background: `#f4f1e7`
- Content surface: `#fffdf6`
- Border: `#d5cebc`
- Brand accent: `#c9f24d`
- Link and focus accent: `#3558c8`

## Typography

Use the native Chinese-capable system sans stack for fast rendering and consistent CJK glyphs. Headlines rely on weight and scale, not a separate display font.

## Shape

Buttons and small controls use 6-8px corners. Content panels remain mostly square. Avoid decorative card nesting and wide shadows.

## Layout

Maximum content width is 1120px. The home hero uses an asymmetric text and decision-panel split on desktop, collapsing to a strict single column below 820px. Articles use a 780px reading column.

## Motion

Static by default. Hover and active feedback use short transform and color transitions. Reduced-motion preferences disable nonessential transitions.
