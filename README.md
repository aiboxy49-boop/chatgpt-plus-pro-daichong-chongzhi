# ChatGPT Plus 国内订阅指南

这是 AI Boxy 的中文内容引流站，使用 GitHub Pages 托管静态教程页面。

## 结构

- `index.html`: 核心指南页
- `articles/`: 长尾专题页
- `styles.css`: 共享视觉样式
- `sitemap.xml`: 搜索引擎站点地图

## 发布

GitHub Pages 使用 `main` 分支根目录发布。页面中的 AI Boxy 链接均带有 UTM 参数，用于区分 GitHub Pages 的自然流量和其他渠道。

## 内容原则

页面以原创教程和风险说明为主体，AI Boxy 作为关联的自有服务透明展示，不冒充 OpenAI、Anthropic 或 Apple 官方页面。
