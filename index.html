提交信息后系统开始处理，进度可以在订单页随时查看。到账后回到 ChatGPT 的账户或套餐页面，确认 Plus / Pro 状态已生效。

不包含。ChatGPT Plus 和 OpenAI API 是两套独立的产品与计费体系，Plus 订阅里包含的是 ChatGPT 和 Codex 的使用额度。
